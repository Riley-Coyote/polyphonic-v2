# Polyphonic mark study

Derived from the canonical Luca 7 × 7 identity glyph in the current luca-unified-dev source: canonicalLucaResident.ts (LUCA_IDENTITY_SEED), identity/glyph.ts. No resident credentials or private keys were used.

Canonical mask:
```
1110111
0011100
0010100
1110111
1000001
1000001
1000001
```

- polyphonic-solid.svg: continuous centerline strokes with round caps and joins. Primary mark; navigation and favicon.
- polyphonic-sharp.svg: original square-ended outline, retained for comparison.
- polyphonic-soft.svg: same cells, exposed corners softened by 0.14 cell. Comparison option.
- polyphonic-matrix.svg: one circular dot per cell, with a dim reference field. Display alternative.
- polyphonic-display.svg: 21 × 21 field, nine dots per original cell. Use at 84px or larger.

All treatments preserve the same silhouette. Keep at least one cell of clear space. Use the joined mark at small sizes; never stretch the glyph. These are design studies, not a trademark clearance.
